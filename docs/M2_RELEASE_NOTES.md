# M2 Release Notes

## M2 - Simulator design

This release packages the completed M2 milestone work for the LIMO project.

### Included work

- Finalised LIMO ISA specification and frozen architecture contract
- M2 simulator design document and block diagram
- Pipeline-register data model covering `IF/ID`, `ID/EX`, `EX/MEM`, and `MEM/WB`
- Hazard and forwarding design documentation
- Interface wireframes and UI layout plan
- Build specification and milestone design references
- AI usage record in `AI_USE.md`
- Live GitHub Pages demo for the project

This milestone established the simulator architecture, pipeline semantics, and assembler/design foundations needed before full execution logic is implemented in M3. The project is ready for the next implementation phase with a stable design contract and documented responsibilities.
