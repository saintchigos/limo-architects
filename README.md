# LIMO

LIMO is a Sesotho-language, RISC-V-derived instruction set architecture together with an
online (web-based) pipeline simulator. It is a CS3520 project by team **Architects**.

## About

- **ISA** — a RISC-V-derived instruction set with Sesotho-language mnemonics and naming.
- **Simulator** — an online simulator that models the datapath and lets you step through
  instruction fetch, decode, execute, memory, and write-back as instructions flow through
  the pipeline.
